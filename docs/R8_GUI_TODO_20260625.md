## R8-1 「参照元（Referral）別セッション数」グラフを総合ビューから削除

**指摘**: 総合ビューの「参照元（Referral）別セッション数」グラフが「チャネル分析」ページと重複。

**手順**:
1. Looker Studio で対象レポートを開く → 右上「編集」
2. 「総合ビュー」ページへ移動
3. 「参照元（Referral）別セッション数」のグラフを1回クリックして選択
4. Delete キー（または右クリック→削除）で削除
5. 右上「表示」に戻して保存（自動保存）

※「チャネル分析」ページ側の同等グラフは残す（重複の解消＝総合ビュー側のみ削除）。

## R8-4 ファネル分析のレイアウト変更（三角形 → 独立到達率）

**指摘/要望**: 三角形のファネル表示は直列の誤解を招く。各ステップは独立到達率なので、
添付モックアップ（`ファネル分析改良依頼_2026.06.25.png`）のレイアウトに変更希望。

**目標レイアウト（クライアント添付モックアップ準拠）**:
```
            主要ページ到達率
  各ステップは独立した到達率です（広告・検索・直接アクセス等から到達）

  [STEP1] 全訪問                                 100%
  ┌────────────────────┬────────────────────┐
  [STEP2] サービス閲覧   |  [STEP3] お問い合わせ到達   ← 横並び（並列）
   12.62%               |   12.69%
  └────────────────────┴────────────────────┘
        ※ STEP2・STEP3 は独立した到達率です
  [STEP4] フォーム入力開始                         8.39%
  [STEP5] 送信完了                                6.34%

  ※各ステップは独立した到達率であり、前のステップを経由することを意味しません
```

**手順案（Looker GUI）**:
1. ファネル分析ページの既存「三角形ファネルチャート」を削除 or 非表示
2. 接続データソース＝`reports.rpt_funnel_long`（STEP3は本日191へ統一済）
3. STEP1 / STEP4 / STEP5 は縦並びの「スコアカード」または横棒で配置
4. STEP2「サービス閲覧」と STEP3「お問い合わせ到達」を**横並び**に配置し、
   その間に注記テキスト「STEP2・STEP3は独立した到達率です」を置く
5. 上部タイトルを「主要ページ到達率」に、下部に注記
   「各ステップは独立した到達率であり、前のステップを経由することを意味しません」
6. 率は ratio of sums（SUM(step)/SUM(STEP1全訪問)）で算出する設定を維持

**補足**: rpt_funnel_long は step_order / step_name / sessions の縦持ち。
率を出す場合は STEP1=全訪問 を分母にした計算フィールド、または既存 rpt_funnel_overview 併用。
レイアウトが複雑なら、7/10の仕上げセッションで画面共有しながら一緒に確定するのが安全。
